Right-click. Inspect. Move on.

Right-click any file in Windows Explorer and get hashes, strings, hex, PE internals, and metadata in a compact popup. Built for reverse engineers and the curious.

01how it works

  1. Run filelens.exe --register once. It adds itself to your right-click menu.
  2. Right-click any file in Explorer and pick Inspect with FileLens.
  3. A popup opens at your cursor with tabs for everything relevant to that file. Click away to dismiss, or pin it.

Remove it again with filelens.exe --unregister. No installer, no admin rights, no service.

02what it shows

InfoSize, timestamps, entropy, magic bytes, type detection and extension mismatch warnings.
HashesMD5, SHA-1 and SHA-256 computed in parallel, with copy buttons.
StringsASCII and UTF-16 strings with a live filter and pills for URLs, paths, IPs and keys.
PESections with entropy, imports by DLL, exports and signing status for EXE / DLL.
HexFirst 64 KB as a hex dump. Click any byte for details.
MetaPDF, Office, JPEG EXIF and PNG chunk metadata. Tabs only show when relevant.
