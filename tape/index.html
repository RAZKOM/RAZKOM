Timestamped music reviews, in a URL.

Pin timestamped notes to a waveform while you listen, then share the review as a link. Only the filename and notes go in the link.

01how it works

  1. Drop an audio file (MP3, WAV, OGG, FLAC, M4A) or tap to pick one.
  2. Play the track. Tap Pin at any moment to drop a timestamped note; playback keeps going while you type.
  3. Drag on the waveform to scrub. Pull down for finer precision.
  4. Tap Share. Your filename and notes compress into the URL and copy to the clipboard.
  5. The recipient opens the link, picks the same file, and every pin appears on the waveform.

No account, no upload, no backend. The link is the storage.

02features

Two modes, one pageNo hash: reviewer mode. A hash: listener mode for the matching file.
Precision scrubbingVertical distance sets the scrub speed, down to 1/16x.
Pins on the waveformTap a pin to seek; the active note highlights as playback reaches it.
URL as storageNotes are LZ-compressed into the hash, well under 2 KB for most tracks.
Filename guardListener mode checks you picked the same file the reviewer used.
Offline readyA single HTML file. Once cached it works offline; host it anywhere.
