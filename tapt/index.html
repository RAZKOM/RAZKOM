04built with authforge

Tapt is a working AuthForge demo. It sells a $2.99 lifetime license with a free trial and runs offline after a single activation, with payments by Stripe and no backend of our own. Everything here is off the shelf, so you can ship the same setup.

  1. The buyer pays through a plain Stripe Checkout linkCommerce
  2. AuthForge receives the Stripe webhook, issues a key and emails itBuyer email
  3. Tapt trades the key for a signed .authforge file bound to this PCRust SDK
  4. Every launch after that verifies the file locally, with no networkOffline files

the licensing code, in shortrust

if client.login_from_file(LICENSE_PATH).is_err() {
    // No file yet, or it's for other hardware: ask for the key and activate once.
    let key = prompt_for_key();
    client.activate_offline(&key, Some(Path::new(LICENSE_PATH)))?;
}
