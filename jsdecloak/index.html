Untangle obfuscated JavaScript

Beautify, deobfuscate, parse, inspect symbols, and run scope-aware renames, without sending code to a backend.

01what it does

Pipeline-based cleanupFormatter and deobfuscation passes in order, then parse and index symbols.
Scope-aware renamesRename a binding and update references safely across scopes.
Analysis panelsSymbols, strings, annotations, diffs and logs while you iterate.
No backendWorker-based processing in the browser. Your code stays in your session.
